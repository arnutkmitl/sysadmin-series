## ก่อนใช้งาน

- ทดลองบน VM ที่ถ่าย snapshot ไว้ก่อนใช้กับ server จริง
- อ่านคำเตือนในเล่มก่อนรันคำสั่งที่ลบไฟล์ ลบผู้ใช้ เปลี่ยนสิทธิ์ แก้ค่า SSH หรือ firewall
  คำสั่งเหล่านี้ทำให้ล็อกอินไม่ได้หรือข้อมูลหายได้ถ้ารันผิดลำดับ
- แก้ชื่อผู้ใช้ IP และชื่อเครื่องในคำสั่งให้ตรงกับเครื่องของคุณ คำในวงเล็บเหลี่ยม เช่น [IP ของ Server]
  คือส่วนที่ต้องแทนด้วยค่าจริง

เล่มนี้ใช้ Rocky Linux เป็นหลัก ไฟล์คำสั่งดึงจากไฟล์ PDF ฉบับจำหน่าย (พิมพ์ครั้งที่ 1 เมษายน 2569)
